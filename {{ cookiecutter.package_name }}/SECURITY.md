# Security Policy

## Supported versions

Only the latest released version of {{ cookiecutter.project_name }} receives
security updates.

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Report privately to [{{ cookiecutter.email }}](mailto:{{ cookiecutter.email }})
with a description of the issue, steps to reproduce, and affected versions.
You will receive an acknowledgement within 72 hours and a fix timeline update
within 7 days.
